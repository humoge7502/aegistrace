# AegisTrace REST API v1

Interactive OpenAPI docs: `http://127.0.0.1:8420/docs` (auto-generated by
FastAPI). Auth: `X-API-Key: at_...` (or `Authorization: Bearer at_...`).
Roles: `admin` › `operator` › `viewer` (read), `agent` (ingest-only).

## Endpoints

| Method | Path | Role | Purpose |
|---|---|---|---|
| POST | `/api/v1/events/batch` | agent+ | ingest SDK events (max 1000/batch; 422 names the bad event index) |
| POST | `/api/v1/baselines` | operator+ | register expected execution contract (sequence / allowed_set / policy_only) |
| GET | `/api/v1/baselines` | viewer+ | list baselines |
| GET | `/api/v1/executions` | viewer+ | list executions (limit/offset) |
| GET | `/api/v1/executions/{id-or-external}` | viewer+ | execution detail (steps included) |
| GET | `/api/v1/executions/{id}/passport` | viewer+ | **AI Execution Passport**: components, outputs, trust decisions, integrity events, certificate |
| GET | `/api/v1/executions/{id}/graph` | viewer+ | causal graph (nodes/edges + deviation flags) for the UI |
| GET | `/api/v1/components` | viewer+ | list components |
| GET | `/api/v1/components/{id}/impact` | viewer+ | executions/outputs/certificates depending on a component (live view) |
| POST | `/api/v1/components/{id}/trust` | operator+ | set state (COMPROMISED triggers full propagation; TRUSTED = recovery) |
| GET | `/api/v1/integrity-events` | viewer+ | recent deviations |
| GET | `/api/v1/incidents` | viewer+ | incidents |
| POST | `/api/v1/incidents/{id}/actions` | operator+ | contain / recover / resolve / rerun_note |
| GET | `/api/v1/certificates` · `/{serial}` | viewer+ | list/get certificates |
| POST | `/api/v1/certificates/{serial}/verify` | viewer+ | verify signature + revocation + subject match |
| GET/PUT | `/api/v1/policies` | viewer / admin | read / update tenant policy rules |
| POST | `/api/v1/auth/keys` | admin | create API key (returned once) |
| POST | `/api/v1/auth/verify` | any | validate key → tenant + role |
| GET | `/api/v1/overview` | viewer+ | dashboard aggregates |
| GET | `/api/v1/audit` | admin | audit trail |
| GET | `/healthz` · `/readyz` · `/metrics` | — | health/readiness/Prometheus counters |

## Event vocabulary (SDK → collector)

| kind | payload |
|---|---|
| `execution.started` | `agent_ref`, `agent_version`, `rerun_of?` |
| `prompt.pinned` | `role`, `hash` |
| `step.ended` | `seq`, `kind`, `target`, `digest?`, `meta?`, `version?` |
| `component.observed` | `kind`, `name`, `version?`, `digest?`, `meta?` |
| `output.produced` | `digest`, `output_kind?`, `output_id?` |
| `execution.finished` | `status` (`completed|failed`) |

## Error contract

- `401` missing/invalid key · `403` insufficient role · `404` not found (or
  other tenant — deliberately indistinguishable) · `422` validation error ·
  `429` rate limited.

## Certificate statement format

```json
{
  "_type": "https://in-toto.io/Statement/v1",
  "subject": [{"name": "execution:<external_id>", "digest": {"sha256": "<fingerprint>"}}],
  "predicateType": "https://aegistrace.dev/attestations/execution-trust/v1",
  "predicate": { "trust_state": "...", "components": [...], "evidence": {...}, "issued_at": "..." }
}
```
Ed25519 signature over canonical JSON (`sort_keys`, compact, UTF-8).
